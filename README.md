# Hogwarts CMS Projekt

### 1. Semester Webudvikling projekt.

Sådan sættes det op:

1. Installer dependencies; kør `npm i`
2. Skab database ved at køre det script'et i `Create Database.sql` is Postgres
3. Sæt op `.env` fil for at forbinde til database
4. Start server via `npm run start`
5. Endpoint collections findes i mappen `Hogwarts DB`; Kør dem via Insomnia, Bruno, eller dit foretrukne API client software.

Serveren lytter på `localhost:6767`. Collections i HogwartsDB har allerede sat adressen op, men måske hjælpsom information.
